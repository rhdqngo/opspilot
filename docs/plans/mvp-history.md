# MVP Checkpoint History

This archive summarizes the completed checkpoints removed from `current.md` when the project moved
to the compact `MVP complete / M9 ready` baseline. Detailed immutable release facts remain in
`docs/portfolio/results/`, ADRs, operations runbooks, and Git history.

## M0-M7 read-only investigation

- M0-M1 established the Python package, private repository, remote Terraform state, WIF plan
  identity, and protected KRW 50,000 budget.
- M2 deployed three private, scale-to-zero demo services and verified authenticated order flow.
- M3 added bounded SCN-001 baseline/incident/recovery execution.
- M4 added the 13-document synthetic Agent Search corpus and deterministic retrieval suite.
- M5 added bounded Logging, Monitoring, revision, and Search evidence collection.
- M6 added the seven-node fixture graph, two tool-free model nodes, citation verification, and
  deterministic scoring/evaluation.
- M7 deployed the managed ADK Runtime and connected the existing Gemini Enterprise app. Several
  recovery iterations established session permission, early progress, bounded hybrid inference,
  Korean/English rendering, anonymous structured logs, and deterministic packaging.

## Portfolio hardening

- Removed milestone-only access, diagnostics, model acceptance, Runtime probe, Enterprise
  registration, backend switching, and other release-only interfaces.
- Added core 7-case and portfolio 40-case deterministic release gates, evidence smoke, reproducible
  demo orchestration, cleanup planning, sanitized publication, and source-bound provenance.
- Kept fixture replay, scenario execution, knowledge validation/sync, evidence collection, CLI/API,
  deterministic package, and Terraform contracts because they are supported public or dynamic
  entrypoints.

## M8 approval-gated remediation

- Implemented an isolated control API, Firestore transaction state, 15-minute Workflow callback,
  payment-only executor, actor-hashed approval, plan hash/expiry/idempotency/lease, and exact
  etag/revision/digest/traffic checks.
- The first cloud apply retained partial state because the Google-managed Workflows service agent
  did not exist. A reviewed recovery created the service identity and Workflow without changing
  existing workloads.
- A fresh SCN-008 execution proved baseline 10/10, fault 0/10, approval-gated rollback, target
  traffic 100%, recovery 10/10, metric windows, reset 10/10, IAM separation, and final Terraform
  `No changes`.
- Removed the one-time fresh/recovery exact address-count branches after evidence publication;
  durable policy still rejects delete/replacement, out-of-scope resources, public invokers, and
  unapproved image digests.

## Persistent investigation completion

- Extended parsing to three catalog services and Korean/English relative windows from 1 to 120
  minutes, with all-service/30-minute defaults and recorded assumptions.
- Added store/task-publisher injection, Cloud Task dedupe/lease, incidents and investigations,
  immutable transactionally versioned reports, report reads, persisted replay, and deterministic
  comparison.
- Added Monitoring/Pub/Sub open/close dedupe that stores only a minimal catalog-bounded incident
  seed and never starts remediation.
- Deployed the private investigation API, task and alert invokers, fixed audience, immutable image,
  and minimum no-delete persistence role. Live Runtime→API→evidence→Firestore, replay/compare,
  duplicate task delivery, and alert open/duplicate/close were verified in dev.

## Pre-M9 cleanup

- Removed the Runtime's historical direct `payment-service`/30-minute evidence/RCA fallback and
  reduced it to a required-API thin adapter with a deterministic minimal package.
- Removed confirmed dead symbols and package-level re-exports while preserving canonical and
  dynamic entrypoints.
- Replaced phase-local Git tuples with one hashed release context and removed duplicate preflight
  environment checks. Durable security, approval, integrity, timeout, and cost gates remain.
- Updated architecture, runbooks, traceability, ADRs, CI readiness/redaction, and the hosted
  Terraform plan-reader contract for the completed MVP.
